# Deepak Gutta — Data Engineer Portfolio

A customized portfolio based on the supplied streaming-series React/Vite template. The original visual direction and interaction patterns are retained, with the content focused on Deepak Gutta's Data Engineering / Snowflake Developer profile.

## Run locally

Requirements: Node.js 20+ and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`). Do not open `index.html` directly or use VS Code Live Server; this is a React/Vite application.

For a production build:

```bash
npm run build
npm run preview
```
